## 🔄 Fallback Behavior

The component will automatically fall back to the product image (`/images/sniff-solve-tower-hero.jpg`) if these CTA images are not available.

## 📏 Recommended Image Specifications

- **Format:** JPG or WebP
- **Dimensions:** 1200x800px or larger
- **Aspect Ratio:** 3:2 or 4:3
- **File Size:** Under 500KB each (optimized for web)
- **Quality:** High resolution, professional photography
- **Style:** Natural lighting, modern home interior, happy dogs

## 💡 Tips

1. Use Unsplash's download feature to get optimized web sizes
2. Select "Medium" or "Large" size (not "Original" to keep file sizes reasonable)
3. Make sure images show dogs that are:
   - Happy and engaged
   - In modern, clean home settings
   - Well-lit with natural lighting
   - Clear and professional quality
